# Expense-_Tracker
A modern Expense Tracker web app built with HTML, CSS, and JavaScript. Users can add and delete expenses, filter by month, calculate total spending, and export data as CSV. All data is stored in localStorage for persistence with a clean and responsive UI.

 **SwiftSpend – Expense Tracker**

SwiftSpend is a simple and modern Expense Tracker Web Application that helps users manage their daily spending. The app allows users to add, delete, and filter expenses while automatically calculating the total amount. All data is stored in localStorage, ensuring that the information remains available even after refreshing the page.

This project is built using HTML, CSS, and Vanilla JavaScript and demonstrates core front-end development concepts such as DOM manipulation, event handling, local storage, and dynamic UI updates.

**🚀 Features**

➕ Add new expenses with title, amount, date, and category

🗑 Delete expenses instantly

📅 Filter expenses by month

💾 Data persistence using localStorage

💵 Automatic total expense calculation

📤 Export expenses as CSV file for Excel

📱 Responsive and clean user interface

**🛠 Technologies Used**

HTML5 – Structure

CSS3 – Styling and responsive design

JavaScript (ES6) – Application logic

LocalStorage API – Data persistence
